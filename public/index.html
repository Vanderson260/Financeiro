📤 Exportar Backup

Baixe um arquivo JSON completo com todas as suas transações, categorias, contas e pessoas. Mantenha-o em local seguro.

📥 Importar Backup

Selecione um arquivo de backup para restaurar seus dados. Atenção: isso substituirá todos os dados atuais.

🗑️ Limpar Dados

Remove permanentemente todos os registros do sistema. Recomendado fazer backup antes.

ℹ️ Informações Importantes

  • O arquivo gerado é no formato .json e pode ser lido em qualquer editor de texto.
  • Ao restaurar, o sistema substitui integralmente os dados atuais.
  • É possível editar o JSON manualmente antes de importar, mas cuidado com a estrutura.
  • Recomenda-se fazer backup semanalmente ou após grandes alterações.
